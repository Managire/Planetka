# Internal Terms And Fair Usage Draft

This draft is superseded by the active Personal / Commercial licence model.

Active model:

- Personal Licence: single-seat, personal and non-commercial use only.
- Commercial Licence: single-seat, required for commercial use.
- Both licences have identical technical access to Planetka features and hosted data.
- Planetka may use licence/API activation, request limits, device/session checks, and abuse controls to protect hosted data and service reliability.
