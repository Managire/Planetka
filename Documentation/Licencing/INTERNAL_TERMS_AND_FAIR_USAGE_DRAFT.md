# Internal Terms And Fair Usage Draft

Superseded by the active Free/Pro Planetka terms.

Current model:

- Product wording is Free and Pro.
- Free uses fair-use, best-effort Planetka Cloud access.
- Pro is the paid production option for support, guaranteed-service arrangements, offline data packages, private deployments, or studio/pipeline integration.
- Free and Pro are installation editions built from the same codebase; backend sessions carry the package edition.
- Planetka Cloud may use anonymous install/session checks, request limits, throttling, and blocking to protect hosted data and service reliability.
