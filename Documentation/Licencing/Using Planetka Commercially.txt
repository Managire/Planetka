Using Planetka Commercially
===========================

1. Planetka account tiers define commercial rights:
   - Free: personal / non-commercial use only
   - Personal: personal / non-commercial use only
   - Commercial: commercial use allowed
2. Current `v0.7.0` beta note: newly issued beta accounts are currently
   provisioned as Commercial by default for testing.
3. If your work is commercial, use Commercial tier.
4. If your work is personal/non-commercial, Free or Personal may be used.
5. If you publish images or animations, include attribution in the accompanying
   text or credits.
6. The easiest way to do that is to use:
   `Attribution for User Renders.txt`
7. Service access, account use, and prohibited scraping / abusive use are
   governed by `TERMS_OF_SERVICE.md`.
8. AI / machine learning use is not included. That includes training, fine-tuning, evaluation,
   benchmarking, and dataset preparation. Those uses require a separate custom
   license from Planetka.

Required attribution summary
----------------------------
Published renders should include credit covering these bundled data sources:

- Contains modified Copernicus Sentinel data (2023).
- Credit: AW3D30 (ALOS World 3D - 30m) (JAXA).

Include this additional line if Night Lights are visible in the published work:

- World Settlement Footprint 2015 (WSF2015 v2), DLR (German Aerospace Center),
  licensed under CC BY 4.0; modified by Planetka.

Planetka credit
---------------
A separate credit to Planetka / Tomas Griger is not required, but appreciated.

Private work
------------
If you do not publish your work, the attribution text is generally not relevant
to your private workflow.
