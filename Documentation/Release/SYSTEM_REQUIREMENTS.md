# System Requirements

Planetka is developed primarily for Blender 5.0 and should be verified on Blender 4.5 LTS and newer supported Blender versions before release.

Planetka is an online texture-streaming product. Creating Earth, checking updates, and resolving Preview, Balanced, or Full Quality data require internet access and Planetka Cloud availability.

## Supported Camera Types

Planetka Resolve supports standard Blender Perspective and Orthographic cameras.

Active View resolving supports Perspective and Orthographic viewport views.

Equirectangular panorama cameras are supported with tile-budget limits. Other panoramic and fisheye camera projections are not currently supported.

## Runtime Access

Planetka connects to Planetka Cloud automatically through an anonymous install session. No email, access key, API key, or in-Blender cloud activation is required.

## Hardware

A GPU capable of handling high-resolution textures is recommended, especially when using Full quality.
