# Planetka System Requirements

These are user-facing requirements for Planetka beta/public use.

## Minimum

- Internet connection (Planetka data is streamed from online storage).
- Blender `4.5.7` or later.
- `16 GB` RAM.
- `64-bit` operating system.
- `10 GB` free SSD space for local cache.

## Recommended

- Blender `5.0+` (best validated path).
- `32 GB` RAM.
- Dedicated GPU (optional, but improves viewport and render speed).
- Fast SSD and stable broadband connection.
