# Archived Tester Release Checklist

Last updated: 2026-05-12

This file is retained only as an internal historical placeholder for early tester-release planning. It is not part of the public package and must not be used as the public-release checklist.

The current public-release process is documented in `Documentation/Release/README.md`.

Current public-release rules:

- Preview is free and personal / non-commercial.
- Full Quality is paid or explicitly granted and includes commercial texture rights for licenced Full Quality data.
- Standard/Balanced, prepaid balance, monthly billing, and unrestricted-quality access are not public-release products.
- Internal release checklists, runbooks, and developer notes must not be packaged for users.
