# Licence Integrity

Planetka no longer uses feature tiers. The active licence options are `personal` and `commercial`.

Both licences have identical technical access to Planetka functionality and hosted data. Backend checks must not block quality modes or features based on Personal versus Commercial licence.

The licence system is still useful for:

- identifying legitimate users;
- protecting hosted data from scraping and abuse;
- revoking compromised access;
- limiting active devices if needed;
- support and recovery;
- distinguishing legal usage rights.

Personal Licence: personal and non-commercial use only.
Commercial Licence: required for commercial use.

Analytics should display Personal / Commercial / Total metrics.
