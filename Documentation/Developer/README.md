# Planetka Developer Notes

- `PRICING_SYSTEM.md` documents that 0.8.2 add-on access no longer uses tile/data-pack pricing and records the legacy website/data-pack system boundary.
- `ERROR_HANDLING.md` documents the project standard for typed exceptions and structured error messages.
- `SCHEMA_MIGRATION.md` documents scene schema versioning and migration steps.
- `DEBUG_REPORT.md` documents the minimal bug-report JSON generated by the extension.
- `HARDENING_BACKLOG.md` tracks prioritized reliability improvements before/after release.
- `INTERNAL_TEST_ACCOUNTS.md` defines the approved internal test accounts and points to the external source-of-truth API key file used for addon/backend/stress tests.
- `ACCOUNT_TIER_INTEGRITY.md` defines the active Free/Indie/Pro account-tier rules, backend enforcement points, and DB audit queries.
- `CLOUD_API_ENV_VARS.md` documents Worker env vars for auth/device rate limits, cleanup cron retention, and log-alert thresholds.
- `TILE_GENERATION_POLICY.md` defines mandatory higher-z/higher-d generation rules, intentional ocean fallback behavior, and the coverage-based distinction between acceptable ocean fallback use and real missing land-tile defects.
- Resolve download-size planning can use a local sqlite tile-size index (`Resources/tile_sizes.sqlite`) to avoid slow remote HEAD probes. Current compact schema is `tile_sizes(folder, x, y, z, d, ext, size_bytes) WITHOUT ROWID` (legacy `key,size_bytes` schema is also read-compatible). Rebuild via `tools/build_tile_size_sqlite_index.py` when source assets change.
- Earth shader tweaks are applied at runtime in `asset_builder.py` via `_ensure_surface_detail_nodes()` (procedural forest/rock bump + optional micro-displacement). New Surface Grading Group inputs: `Procedural Detail Scale`, `Forest Detail Strength`, `Rock Detail Strength`, `Rock Color Variation`, `Micro Displacement Strength`.
- CRITICAL SAFETY RULE (DO NOT VIOLATE): PLANETKA CODE MUST ONLY MODIFY PLANETKA OBJECTS. NEVER READ/WRITE/REPLACE/ANIMATE NON-PLANETKA OBJECTS (CAMERAS, LIGHTS, MESHES, OR ANY OTHER USER ASSETS).
